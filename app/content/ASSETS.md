# 3D model library: owner's choices (Nov 20)

Plan: for every thing a line says, look it up first in free model libraries (several sites), then build it from
simple shapes only if nothing fits. Never a random street instead. People stay as they are now (our own
characters). Not for the gravity video; for the next ones.

Style the owner chose: simple, geometric, "made with code", never realistic.
- Trees / nature: Quaternius "Simple Nature" (CC0) - https://quaternius.com/packs/simplenature.html
  (Central Park and parks: fill them with these trees).
- Airplane: "Low Poly Boeing 787 Dreamliner" on Sketchfab (CC-BY: credit the author in the description) -
  https://sketchfab.com/3d-models/50baa323fabd49a6b861096cb88e5c25
- Rejected: realistic textures (Sketchfab oak / forest pack, "simple cat"), soft cartoon blobs, pixel characters.

Sites checked: Quaternius (CC0, reachable), Sketchfab API (search works; downloads need an account token),
OpenGameArt (CC0/CC-BY, reachable). Kenney and Poly Pizza block automated requests from the runners.
Animals: Quaternius "Ultimate Animated Animals" (CC0, animated, no cat); OpenGameArt "Animated animales low poly"
(CC0, has a cat). Meteor: a rock (Quaternius space kit) + the engine's fire/explosion/crack.
